Functional Amendments & Feature Enhancement Specification
Prepared for: Development Team
Project: Tinaska Love Diary
Date: September 2026

Introduction
The following document outlines the requested improvements and feature enhancements for the Tinaska Love Diary web application. The objective is to improve usability, synchronization between partners, editing flexibility, data organization, and media performance while preserving the existing user experience.

1. Shared Countdown System
Current Issue
The countdown is currently visible to only one individual partner.
Required Changes
Convert countdowns into shared couple events.
Both partners should:
•	View the same countdown.
•	Receive real-time updates.
•	Edit countdown details.
•	Delete countdowns when necessary.
After a countdown expires:
•	Keep it in history.
•	Allow editing or deletion.
•	Provide an option to restart or create a new countdown.
Anniversary Countdown
Update the anniversary countdown to begin from:
4 September 2025
The system should automatically calculate:
•	Years
•	Months
•	Weeks
•	Days
•	Hours (optional)

2. Letters Page Improvements
Deletion
Users should be able to:
•	Delete any letter at any time.
•	Edit previously written letters.
Organization
Arrange letters according to:
•	Newest first
•	Oldest first
Provide filters:
•	Daily
•	Monthly
•	Yearly
Optional
•	Search letters by keyword.

3. Idea Wheel Enhancement
Split the feature into two independent modes.
A. Couple Spin
Both partners participate.
Requirements:
•	Result appears to both users.
•	Shared history of spins.
•	Timestamp for every spin.
Examples:
•	Movie Night
•	Ice Cream Date
•	Long Walk
•	Surprise Gift
B. Private Spin
Each partner spins privately.
Requirements:
•	Results remain visible only to the person spinning.
•	No synchronization.
•	Optional save/delete history.

4. Plans & Goals Module
Current functionality includes
•	Cancel
•	Done
Required additions
•	Edit plan
•	Delete plan
Editing should allow modification of:
•	Title
•	Description
•	Date
•	Priority
•	Status
The existing Done and Cancel actions should remain unchanged.

5. Timeline Page
Enhance the timeline into a dynamic chronological history.
Requirements:
•	Add new timeline entries.
•	Edit timeline entries.
•	Delete timeline entries.
•	Automatically arrange entries chronologically.
Display:
•	Date
•	Title
•	Description
•	Photos (optional)

6. Memory & Letters Editor
The current writing area feels limited.
Increase editor usability by:
•	Wider writing area.
•	Larger text box.
•	Comfortable spacing.
•	Better formatting support.
Optional enhancements
•	Bold
•	Italic
•	Underline
•	Bullet lists
•	Emoji support
•	Auto-save drafts

7. Media Upload Optimization
Current Problems
•	Images upload slowly.
•	Videos upload slowly.
•	Some media never uploads successfully.
Required Improvements
Investigate and optimize:
•	Upload speed.
•	File compression.
•	Storage performance.
•	Network handling.
•	Progress indicators.
•	Retry mechanism after failed uploads.
Recommended additions
•	Upload progress bar.
•	Success notification.
•	Error messages with retry option.

8. General Performance Improvements
Improve:
•	Loading speed.
•	Database synchronization.
•	Real-time updates.
•	Mobile responsiveness.
•	Overall application stability.

9. User Experience Improvements
Where applicable:
•	Confirmation dialog before deleting content.
•	Success notifications after edits.
•	Better loading animations.
•	Consistent button placement.
•	Improved spacing across pages.

Summary of Requested Enhancements

Module	Requested Improvements
Countdown	Shared visibility, edit/delete, expired event management, anniversary starts on 4 Sept 2025
Letters	Edit, delete, chronological ordering, daily/monthly/yearly filters, optional search
Idea Wheel	Shared Couple Spin + Private Spin
Plans & Goals	Edit and delete while keeping Done and Cancel
Timeline	Add, edit, delete, chronological ordering
Memory & Letters	Larger writing/editing area with improved usability
Media	Faster uploads, reliable image/video storage, retry mechanism, upload progress
Performance	Better synchronization, responsiveness, and loading speed
UX	Confirmation dialogs, notifications, cleaner interface


Final Note
The objective of these changes is to improve collaboration between both partners, enhance flexibility when managing personal content, and significantly improve the overall user experience and performance of the Tinaska Love Diary application. All new features should integrate seamlessly with the existing design while maintaining data consistency, reliability, and real-time synchronization across both partners' accounts.
